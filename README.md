# 📍 Apify Map Scraper (Thailand)

สคริปต์ Node.js สำหรับดึงข้อมูลสถานที่ต่างๆ จาก Google Maps ผ่าน [Apify API](https://apify.com/) (เช่น กวดวิชา, ติวเตอร์) ตามรายชื่อจังหวัดที่กำหนด และบันทึกผลลัพธ์ที่ได้ออกมาเป็นไฟล์ `.csv` แยกตามจังหวัดโดยอัตโนมัติ

---

## 🚀 การติดตั้ง (Setup)

1. **ติดตั้ง Dependencies** ในโปรเจกต์ (หากยังไม่ได้ติดตั้ง):
   ```bash
   npm install
   ```

2. **ตั้งค่า API Token**:
   * คัดลอกเนื้อหาหรือสร้างไฟล์จาก `.env example` โดยเปลี่ยนชื่อเป็น `.env`
   * แก้ไขค่า `APIFY_API_TOKEN` ให้เป็น Token จริงของคุณจาก Apify
   ```env
   APIFY_API_TOKEN=your_real_token_here
   ```

---

## 💻 วิธีการใช้งาน (Usage)

1. เปิดไฟล์ `scraper.js` ขึ้นมา
2. นำรายชื่อจังหวัดที่ต้องการสแครป ไปใส่ไว้ในตัวแปร `stateList` (บรรทัดที่ 11)
   
   > ⚠️ **ข้อควรระวัง:** แนะนำให้ใส่รายชื่อจังหวัดใน `stateList` **สูงสุดไม่เกิน 4 จังหวัดต่อการรัน 1 ครั้ง** เพื่อป้องกันปัญหาข้อมูลเกินขีดจำกัด (Memory/Timeout)

   **ตัวอย่าง:**
   ```javascript
   // scraper.js (บรรทัดที่ 11)
   const stateList = ["ระยอง", "พระนครศรีอยุธยา"];
   ```

3. รันสคริปต์ได้ด้วยคำสั่ง:
   ```bash
   node scraper.js
   ```
4. เมื่อทำงานเสร็จสิ้น ไฟล์ข้อมูล `.csv` จะถูกบันทึกไว้ในโฟลเดอร์ `results/`
